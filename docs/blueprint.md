# **App Name**: AIDOC

## Core Features:

- AI Diagnosis: Analyze patient data and symptoms using an AI tool to generate potential diagnoses.
- Diagnosis Display: Display a ranked list of possible conditions with clear explanations and urgency levels.
- Condition Details: Provide detailed information on each diagnosis, including possible causes and recommended next steps.
- Profile Management: Securely store and manage patient profiles and symptom history.
- User-Friendly Input: Present a clean, intuitive interface for entering patient data and reviewing diagnoses.

## Style Guidelines:

- Primary color: Calming blue (#5DADE2) to instill trust and serenity.
- Background color: Light, desaturated blue (#F0F8FF) for a clean, clinical feel.
- Accent color: Muted green (#A3E4D7) to highlight important information and actions.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable interface.
- Use clear, universal icons for symptoms and conditions. Focus on line icons for clarity.
- Prioritize a clean, organized layout with clear hierarchy and spacing for easy navigation.
- Subtle transitions and animations to guide the user and provide feedback, without being distracting.

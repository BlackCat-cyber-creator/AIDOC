This directory is intended to store 3D GLB models for the human anatomy. 

Please place your `male_anatomy.glb` and `female_anatomy.glb` files directly into this `public/models/` directory.

Example:
- `public/models/male_anatomy.glb`
- `public/models/female_anatomy.glb`

These models will be loaded by the `HumanAnatomy3D` component to display interactive 3D anatomy.
